# Круг 46 — SHELL: проекты без сервера (заметки для SPEC)

## Хранилище (src/shell.js, раздел «круг 46»)
- `openSoloStore(env)`: тела в IndexedDB `imago-projects`/`bodies` → иначе localStorage `imago.project.<id>`
  (warn 'local', запись > 2 МБ → `big`) → иначе память (warn 'memory'). Нет рабочего localStorage —
  всё в памяти (индекс без него не переживёт перезагрузку).
- Индекс `imago.projects.v1` в localStorage: `{v, list:[{id,name,created_at,updated_at,boards,nodes,bytes,view,board,tab}], current}`.
- Конфликт двух вкладок: `write(id, payload, {base})` отказывает `{conflict}`, если в индексе запись новее `base`
  и её сделала другая вкладка (`tab`). `force:true` — «Оставить мою».
- Уход со страницы: `saveOnExit` пишет синхронно `imago.projects.exit.v1`; `adoptExit` при открытии переносит
  в тело, только если запись новее тела.
- Канал `BroadcastChannel('imago-projects')`: `{type:'list'}`, `{type:'saved', id, updated_at}`; без канала —
  событие storage на ключе индекса.
- Хранилище положено в shell.js, а не в отдельный модуль: список модулей сборки (tools/build.mjs SRC_MODULES)
  проверяет deploy.test, а tools/ — не мои файлы.

## Оболочка (app.js)
- Перенос: проектов нет и нет метки `imago.projects.migrated.v1` → прежний путь (db `docs/current` /
  `imago.doc.v1`) и документ становится первым проектом с его именем; метка — чтобы удалённый позже
  последний проект не воскресал из старого ключа. Старый ключ не трогается и больше не пишется.
  Непрочитанный прежний документ — прежняя карточка; «Начать заново» заводит первый проект.
- Переключение: стоп агента → ждём конца прогона (до 4 с; не кончился — «Агент ещё заканчивает команду»,
  не переключаем) → сохраняем открытый (не сохранился — «другой не открываю») → открываем. Выделение,
  полная история и разговор — в сессии на проект (берутся, если тело с ухода не менялось), иначе из тела.
  Вид и активная доска — в индексе.
- Другая вкладка сохранила открытый проект: здесь правок нет — тихо берём свежую версию (тост); есть —
  плашка «Проект изменён в другой вкладке — Открыть свежую версию / Оставить мою», сохранение стоит;
  закрыли крестиком — плашка вернётся при следующей правке.
- Кнопка в шторке — «Создать проект», как в серверной (круг 29, п.7: иначе две строки «Новый проект»
  подряд); новый проект называется «Новый проект», «Новый проект 2»…
- Удаление — подтверждение в строке (confirm() в артефакте не работает), тост «Удалил «…» — Вернуть»
  (тело держится, пока тост на экране).
- Импорт JSON без сервера — новым проектом; экспорт без изменений.
- Команды таблицы (группа «Файл»): projects (Mod+O), project-new, project-open, project-rename,
  project-duplicate; на сервере — та же серверная шторка, копия — POST /api/projects телом rescuePlan.
