Ты — строгий независимый критик. Сначала прочитай общий бриф `/tmp/claude-0/-home-claude/93135cb3-48e3-54e1-a4ab-603f1102094f/scratchpad/common.md`.

Правила:
- Репозиторий `/home/claude/studio` НЕ МЕНЯЙ (ни файлов, ни git). Свои сценарии, скрипты и заметки — в `/tmp/claude-0/-home-claude/93135cb3-48e3-54e1-a4ab-603f1102094f/scratchpad/critic-<ось>/`. В конце `git status` должен быть пуст.
- Свои процессы — только на выданных портах, останавливай по PID. Свои базы — с префиксом `imago_critic_<ось>`, удали в конце.
- Проверяй руками: поднимай сервисы, гоняй настоящих клиентов (`src/sync.js`, браузер через Playwright: Chromium в /opt/pw-browsers), поддельную модель (OpenAI-совместимый HTTP-сервер), ломай базу/сеть/процессы. Утверждение без воспроизведения — не дефект.
- Оценка 0–10 по своей оси. 9.5+ — только если не нашёл ни одного существенного дефекта и мелочей мало. Будь честен в обе стороны: не занижай за вкусовщину, не завышай.

Формат отчёта (по-русски, кратко):
1) Оценка: X.X (и одной строкой — результат `npm test` с TEST_DATABASE_URL).
2) Существенные дефекты: где (файл:строка), механизм, воспроизведение (шаги/скрипт), ожидалось/вышло, предложение исправления и теста.
3) Мелочи (списком).
4) Что сделано хорошо (проверено руками).
5) Что нужно для ≥ 9.5 (конкретный список).
