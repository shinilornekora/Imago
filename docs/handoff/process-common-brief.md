# Imago Studio — общий бриф для агентов (исполнителей и критиков)

Репозиторий: `/home/claude/studio` (git, ветка master). Язык кода — JS (ESM, Node 22), комментарии, строки интерфейса, коммит-сообщения и отчёты — по-русски.

## Что это
AI-first редактор макетов. DSL структурный: auto-layout без хранимой геометрии, детерминированный решатель (`src/core.js`) считает геометрию. Пять операций: create, remove, set, move, setToken. Агент (`src/brain.js`) превращает речь человека в патч → операции. Оболочка — `app.js` + `index.html` + `styles.css` (дизайн уже есть — НЕ переделывать стиль, только встраивать новое в существующий визуальный язык).

## Архитектура (нормативно — SPEC.md §8, §9, §10; читать перед работой)
- CLIENT (браузер): оболочка + `core`; реплика `src/sync.js` (IndexedDB-журнал, очередь, сокет, отмена транзакциями, присутствие).
- NGINX: статика, `/api` и `/ws` → Document service, `/agent` → Orchestrator.
- Document service (`server/document/`): DSLR (чтение), DSLTS (секвенсор, единственный писатель), Hub (WebSocket). PostgreSQL: журнал операций — источник истины, снимки — производная.
- Orchestrator (`server/orchestrator/`): JEV, DUIL, DSLV, LLM, клиенты DSLR/DSLTS; к базе НЕ прикасается.
- Модель согласованности: CP по проекту, но клиент не блокируется (реплика), жертвуем актуальностью. Слияние не отказывает (`core.rebase`, `dropped`).

## Правила работы
- Владей ТОЛЬКО своими файлами (перечислены в задаче). Чужие файлы не трогай; если без правки чужого файла нельзя — опиши нужную правку в отчёте.
- Тесты: `cd /home/claude/studio && TEST_DATABASE_URL=postgres://imago:imago@127.0.0.1:5432/imago_test env -u NODE_OPTIONS npm test`. Postgres: если не отвечает — `pg_ctlcluster 16 main start`. Для своих баз создавай отдельную (`createdb -U imago -h 127.0.0.1 <имя>`, пароль imago) и удаляй за собой. Порты для своих процессов — бери из выданного диапазона; останавливай процессы по PID.
- ВАЖНО: параллельно работают другие агенты. Полный прогон тестов делай на СВОЕЙ базе: `createdb -U imago -h 127.0.0.1 imago_test_<твоё-имя>` и `TEST_DATABASE_URL=postgres://imago:imago@127.0.0.1:5432/imago_test_<твоё-имя>`; удали её в конце. Общую `imago_test` не используй.
- `NODE_OPTIONS` всегда снимай (`env -u NODE_OPTIONS`) — он ломает лимиты кучи воркеров.
- Не коммить: коммитит координатор. Оставь рабочее дерево с изменениями и все тесты зелёными.
- Пороги в тестах на время — относительные или с запасом, чтобы не флапали под нагрузкой.
- Без секретов в коде, логах, ответах. Сеть наружу не нужна; LLM в тестах — поддельный локальный HTTP-сервер.
- Финальный отчёт: что сделано (файлы), что проверено (число тестов, сценарии), что осталось/риски, какие правки нужны в чужих файлах. Коротко, по-русски.
