# План круга 94: зен-режим

## Технический контекст
Оболочка без сборки (`index.html`, `styles.css`, `app.js`), таблица команд `src/shell.js`. Формат
документа и сервер не меняются. Голос уже есть (`initVoice`, круги 15–18): распознавание пишет в
`dom.command`, команда идёт через `handleVoiceUtterance`; голосовая сессия уже прячет строку команды и
держит микрофон в правом нижнем углу (`#voicebar`). Ход работы уже живёт справа сверху (`#worklog`).

## Решение
- `data-zen="on"` на `#app` + CSS: колонки рельса и инспектора и строка шапки — 0, панели — `display:none`.
  Не через `data-rail`/`data-insp` — чтобы не трогать их настройки.
- `#zenbar` (статус + «Выйти») в холсте; во время работы прячется, `#worklog` поднимается на `top: 12px`.
- `#btn-zen-mic` в доке — та же `.voice-mic`, но спокойная; нажатие → `toggleVoice()`.
- `showMsg` помечает сообщение `data-zen-quiet` (итог, ответ, итог с замечанием) и пишет `state.zenLast`.
- Команда таблицы `zen` (группа «Вид», `Mod+\`), `RE_ZEN_ON/OFF`, `SLASH_ARGS.zen`, `shellIntentFromServer`.
- `settings.zen` в `imago.settings.v1`; `applyZen()` в `boot`.
