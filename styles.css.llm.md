# `styles.css` — заметка для LLM

> Сайдкар: карта файла для отладки. Источник истины — код и SPEC.md. Меняешь файл — обнови заметку в том же коммите (конституция, принцип VII; проверка — `node tools/sidecars.mjs`).

## Назначение
Стили оболочки (не макета!): токены интерфейса в `:root` (тёмная студия по умолчанию), светлая тема переопределяет только значения, вёрстка панелей, холста, ленты агента, инспектора, шторок, мобильная раскладка.

## Инварианты
- Оранжевый принадлежит документу (токен `accent` макета); интерфейс берёт холодный индиго `--accent` — кнопки оболочки и макета не спорят за внимание.
- Контрасты по WCAG: контур управляемых элементов ≥ 3:1 (`--line-strong`, 1.4.11), мелкий текст ≥ 4.5:1 (отдельные оттенки вроде `--danger-pill`).
- `[hidden]{display:none!important}` ставит сборка в `<head>` — элементы прячутся атрибутом.

## Подводные камни
Цвета макета на холсте рисует ядро (`core.Stage`, токены документа и тема доски §15) — их здесь не искать.

- Тема экрана в инспекторе: `.theme-color-*`, `.theme-font-*`, `.theme-style-*` (круг 73, «Шрифты по стилям»), `.theme-part-reset` (круг 78, ряд кнопок частей темы); в списке слоёв — `.tagpill.theme` с `.dot` (узкая, как метка состояний; щёлкается — §15.18) и запасы имени `.layer[data-theme="on"]`, вместе с состояниями — `[data-states][data-theme]` (круг 81) — имя слева, выборы растягиваются.
