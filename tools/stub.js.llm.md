# `tools/stub.js` — заметка для LLM

> Сайдкар: карта файла для отладки. Источник истины — код и SPEC.md. Меняешь файл — обнови заметку в том же коммите (конституция, принцип VII; проверка — `node tools/sidecars.mjs`).

## Назначение
Заглушка платформы claude.ai для локального прогона (`dev.html`): классический скрипт, ставит `window.claude` с детерминированными ответами «модели» — оболочку можно гонять в браузере без сети и без ключа.

## Главное
- `window.claude.sample(input, opts)` (`sampleFn`), `.json`, `.limits()` → `{images:false}`; журнал вызовов `calls`.
- Ответ выбирается по имени схемы из промпта (`schemaNameOf`: «Схема "plan"» и т.п.) и последней реплике человека (`lastUser`).
- Иллюстрации (круг 37, §12.2): «нарисуй/монстр/печенька…» — монстрик из `core.sampleIllustration` (ядро грузится динамическим импортом), печенька — своя.

## Подводные камни
Ответы заглушки — контракт, на который опирается `tools/smoke.mjs`: меняешь схемы brain (`SCHEMAS`) — проверь, что заглушка всё ещё отвечает их формой.
