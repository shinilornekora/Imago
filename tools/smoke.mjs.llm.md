# `tools/smoke.mjs` — заметка для LLM

> Сайдкар: карта файла для отладки. Источник истины — код и SPEC.md. Меняешь файл — обнови заметку в том же коммите (конституция, принцип VII; проверка — `node tools/sidecars.mjs`).

## Назначение
Дымовой прогон оболочки в настоящем Chromium (Playwright) по `dev.html` с заглушкой: шаги «svg отрисован», «слои заполнены», «клик по узлу выделяет», «команда агента создаёт узлы», «история содержит транзакцию агента», «undo/redo», «варианты», «зум». Печатает `OK/FAIL` по шагам и собирает ошибки консоли, `pageerror`, `requestfailed`.

## Запуск
`node tools/build.mjs`, поднять статику (`python3 -m http.server 8777`), затем `URL=http://127.0.0.1:8777/dev.html OUT=<папка> node tools/smoke.mjs`.

## Подводные камни
- Импорт Playwright — по абсолютному пути глобальной установки из старой сессии (`/home/claude/.npm-global/...`), и `OUT` по умолчанию — чужая папка: в новой среде замени на `require('playwright')`/`import('playwright')` и передай `OUT`.
- Не часть `npm test`.
