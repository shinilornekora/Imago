# `tools/shots.mjs` — заметка для LLM

> Сайдкар: карта файла для отладки. Источник истины — код и SPEC.md. Меняешь файл — обнови заметку в том же коммите (конституция, принцип VII; проверка — `node tools/sidecars.mjs`).

## Назначение
Снимки экрана оболочки для отчётов критикам: десктоп 1512×900 в тёмной и светлой теме (`colorScheme` + настройки в `localStorage` `imago.settings.v1`) и мобильная ширина с чистым профилем.

## Подводные камни
Как и smoke.mjs: путь к Playwright и папка `OUT` захардкожены под старую сессию — поправь перед запуском. `colorScheme` обязателен: без него режим «как в системе» давал светлый кадр в обоих файлах.
