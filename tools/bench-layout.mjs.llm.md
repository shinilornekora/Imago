# `tools/bench-layout.mjs` — заметка для LLM

> Сайдкар: карта файла для отладки. Источник истины — код и SPEC.md. Меняешь файл — обнови заметку в том же коммите (конституция, принцип VII; проверка — `node tools/sidecars.mjs`).

## Назначение
Замер раскладки (круги 51, 57, 66; SPEC §18): полная `core.solve` против «по месту правки» `core.solveAfter`, отмена той же правки `core.solveNext` и догон пяти правок. Медиана из `--runs`.

## Запуск
`node tools/bench-layout.mjs [--nodes 1000,5000] [--runs 30] [--shape flat|nested] [--json]`

## Главное
- `boardDoc(n)` — одна доска, карточки по 4 слоя сеткой с переносом; правка — текст средней карточки.
- `nestedDoc(n)` (круг 66) — доска-колонка → секции → ряды с переносом → карточки → тексты (глубина 5, как лендинг).
- Измеритель текста без холста (приближение ширины) — важна доля раскладки, не точность.

## Инварианты
Каждый быстрый путь сверяется с полной раскладкой по `core.hashGeometry`; расхождение — исключение (бенч одновременно — грубый тест корректности).
