# `src/swatches.js` — заметка для LLM

> Сайдкар: карта файла для отладки. Источник истины — код и SPEC.md. Меняешь файл — обнови заметку в том же коммите (конституция, принцип VII; проверка — `node tools/sidecars.mjs`).

## Назначение
Цвета картинок документа для арт-директора (круг 53, SPEC §20): модель без зрения картинок не видит, поэтому цвета считает приложение по пикселям, детерминированно, и отдаёт строкой в промпт. Только чистые функции; пиксели добывает тот, у кого есть чем: оболочка — canvas, сервер — resvg (`server/orchestrator/render.js`).

## Главное
- `SWATCH_LIMITS = {images:4, colors:5, minShare:0.02, side:48, maxSrc:6 МБ}`, `SWATCH_MAX_PIXELS`.
- `paletteFromPixels(data, w, h, {count, minShare})` → `[{hex, share}]` по убыванию доли: корзины по 4 бита на канал → жадное слияние близких (`MERGE_DIST`); прозрачные (α < 128) не считаются.
- `imageSources(doc, selection, geo)` — какие картинки брать: выделение, доска, образец (§21).
- `imageColorsLine(list)` — строка для промпта; `srcKey(src)` — ключ кеша; `encodedSize(b)` — размер data:-адреса.

## Инварианты
Детерминизм: одинаковые пиксели — одинаковая палитра (тесты сравнивают точно).
