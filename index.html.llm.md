# `index.html` — заметка для LLM

> Сайдкар: карта файла для отладки. Источник истины — код и SPEC.md. Меняешь файл — обнови заметку в том же коммите (конституция, принцип VII; проверка — `node tools/sidecars.mjs`).

## Назначение
Тело страницы оболочки (без `<html>/<head>`: так его принимает артефакт claude.ai): шрифты IBM Plex и Instrument Serif, `styles.css`, разметка панелей — шапка (рельс, имя документа, «Проекты», состояние синхронизации и агента, вкладки досок), холст, рельс слоёв, инспектор, строка команды, шторки, тосты. Полный документ из него собирает `tools/build.mjs` (dev.html, dist/local, dist/web).

## Инварианты
- id элементов — контракт с `app.js` (`el(id)`, `dom.*`): переименовал id — найди его в app.js.
- Серверные элементы (`btn-projects`, `sync-status`, `agent-status`) по умолчанию `hidden` — без сервера оболочка работает как прежде.
- Иконки — `<span class="i" data-icon="…">`, рисует app.js (раздел «иконки»).
