# `examples/pechenka-kliker.build.mjs` — заметка для LLM

> Сайдкар: карта файла для отладки. Источник истины — код и SPEC.md. Меняешь файл — обнови заметку в том же коммите (конституция, принцип VII; проверка — `node tools/sidecars.mjs`).

## Назначение
Генератор примера `examples/pechenka-kliker.json` («Печенька-кликер»): `node examples/pechenka-kliker.build.mjs examples/pechenka-kliker.json`. Собирает документ кодом через `core.ops` и `brain.treeToOps`: тёплая палитра токенами, векторная иллюстрация печеньки, состояния и движение (круг 36), экраны.
