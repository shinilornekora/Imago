# `server/orchestrator/traces.js` — заметка для LLM

> Сайдкар: карта файла для отладки. Источник истины — код и SPEC.md. Меняешь файл — обнови заметку в том же коммите (конституция, принцип VII; проверка — `node tools/sidecars.mjs`).

## Назначение
Трассы команд агента (SPEC §10.4): шаги, длительности, число вызовов модели, токены, арт-направление (палитра и шрифты, §14.5) — без ключей и промптов.

## Главное
`createTraces({doc, token, path, redact, log})` → `{record, recent, flush}`: отправка `POST {DOCUMENT_URL}/api/internal/traces` с `X-Internal-Token` + кольцо последних `TRACE_RING` трасс в памяти. `cleanArt` — в трассу только роли палитры `#rrggbb` и имена семейств.

## Инварианты
Не дошло (нет эндпойнта, 403, сеть) — команда этого не замечает; в лог одна строка (одинаковая причина подряд — один раз).

## Отладка
Без INTERNAL_TOKEN трассы только в памяти. Прямых тестов нет — проверяется через `test/orchestrator/orchestrator.test.mjs`.
