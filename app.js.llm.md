# `app.js` — заметка для LLM

> Сайдкар: карта файла для отладки. Источник истины — код и SPEC.md. Меняешь файл — обнови заметку в том же коммите (конституция, принцип VII; проверка — `node tools/sidecars.mjs`).

## Назначение
Оболочка редактора в браузере (≈16 тыс. строк, ES-модуль без сборки): панели, холст (`core.Stage`), строка команды, голос, история, инспектор, шторки, проекты, сохранение, настройки. Связывает ядро (`src/core.js`), мозг (`src/brain.js`), реплику сервера (`src/sync.js`), клиента агента (`src/agent.js`) и слова/таблицу команд (`src/shell.js`). Три режима: артефакт claude.ai (`claude.use("sample")`), соло-сборка (LM Studio, проекты в браузере), серверный режим (Document service + Orchestrator).

## Инварианты
- Правка документа — только операциями ядра через `commit` (одна транзакция = один шаг отмены); оболочка не заводит своих структур документа.
- Поля шкал читаются только через ядро (`resolveLayout`/`resolveRadius`/`resolveScale`, §6.3).
- Перечня команд в app.js нет: справка и палитра строятся из `SHELL_COMMANDS` (проверяет `test/shell-r38.test.mjs` — app.js не должен держать названия команд сам).
- Команда, принятая сервером, в браузере не повторяется (`AgentError.accepted`).

## Подводные камни
- `boot()` стоит в конце файла: ему нужны константы, объявленные ниже, — не переносить вызов наверх.
- Новый модуль `src/*.js` — добавить в `SRC_MODULES` в `tools/build.mjs`.
- Прямых юнит-тестов у app.js нет: тесты читают его текстом (`shell-r36/38/39b/43/45`, `brain.test`, `deploy`) или гоняют в Chromium (`tools/smoke.mjs`).

## Отладка
`node tools/build.mjs`, `python3 -m http.server 8777`, открыть `dev.html` (заглушка модели) или `dist/local/index.html`; дым — `tools/smoke.mjs`.
