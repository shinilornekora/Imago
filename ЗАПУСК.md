# Запуск Imago Studio

## Совместная работа (сервер) — Docker Desktop

1. Установить и запустить Docker Desktop.
2. Двойной клик по `START.cmd` в корне репозитория (или `docker compose up --build -d`).
3. Открыть http://localhost:8123/ — создастся первый проект, ссылка вида `?project=<id>`.
   Эту ссылку можно открыть во втором окне или на другой машине в той же сети
   (`http://<ip-компьютера>:8123/?project=<id>`) — правки видны вживую.
4. Остановить — `STOP.cmd`; база остаётся в томе `imago-db` (`docker compose down -v` — стереть).

Что поднимается: PostgreSQL 16, Document service (`server/document`, DSLR + DSLTS + Hub),
NGINX со статикой клиента и прокси `/api`, `/ws`. Порт меняется переменной `IMAGO_PORT`.

Агент в этом круге работает в браузере: LM Studio на http://localhost:1234/v1 машины, где
открыт браузер (шестерёнка → «Агент»).

Без сети клиент продолжает работать: правки копятся в браузере (IndexedDB), переживают
перезагрузку вкладки и досылаются, когда сервер вернулся; в шапке — «сервер недоступен · N правок ждут».

## Без Docker

* Свой PostgreSQL: `npm install`, затем
  `DATABASE_URL=postgres://… STATIC_DIR=. PORT=8123 node server/document/index.js` — сервис
  сам отдаёт клиент, NGINX не нужен.
* Соло без сервера: `node tools/build.mjs`, затем `dist/local/START.cmd` — прежний режим,
  документ в localStorage.

## Тесты

`npm test` — все; с базой: `TEST_DATABASE_URL=postgres://… npm test`.
